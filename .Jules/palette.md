## 2024-05-24 - Keyboard Accessibility for Custom Non-Semantic Interactive Components
**Learning:** This app relies on custom UI components (`MCItem`, `MCButton`, `MCSlot`) built using non-semantic tags like `div` and `img` for stylistic reasons (pixel art buttons, etc). These elements were lacking built-in accessibility. Adding an `onClick` handler to a `div` or `img` is not enough; screen readers won't announce it as a button, and keyboard users cannot tab to it or trigger it.
**Action:** When creating or modifying non-semantic UI components that act as buttons, always add `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler to simulate click behavior on 'Enter' or ' ' (Space) keys. Ensure these are conditionally applied if the interactive behavior itself is optional (e.g., conditionally dependent on an `onClick` prop).
