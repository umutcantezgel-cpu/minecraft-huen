## 2024-11-10 - Keyboard Accessibility for Interactive Non-Semantic UI Components
**Learning:** Custom UI components built with non-semantic tags like `div` or `img` (such as `MCButton`, `MCItem`, and `MCSlot`) completely lack keyboard accessibility by default. When an `onClick` handler is applied, these elements are essentially invisible to keyboard users and cannot be focused or triggered without a mouse.
**Action:** When a non-semantic element is given an `onClick` prop, always pair it with `role="button"`, `tabIndex={0}`, standard focus indicators (`focus-visible:ring-2 focus-visible:ring-white focus-visible:outline-none`), and an `onKeyDown` handler listening for 'Enter' and 'Space' (using `e.preventDefault()` for Space to prevent scroll) to ensure comprehensive accessibility parity.
