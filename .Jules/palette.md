## 2025-02-23 - Keyboard accessibility for non-semantic interactive components
**Learning:** Custom UI components using non-semantic HTML tags (like `div` or `img`) with an `onClick` prop must explicitly include `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler for 'Enter' and ' ' (Space) to ensure full keyboard accessibility. Furthermore, calling `e.preventDefault()` on Space is critical to prevent the default browser behavior of scrolling the page down.
**Action:** Always verify keyboard focus and interactions when creating custom generic components like `MCButton`, `MCSlot`, or `MCItem` that don't inherently support tab focus or keyboard events, applying `focus-visible:ring-2 focus-visible:ring-white focus-visible:outline-none` for a clear visual focus indicator.
