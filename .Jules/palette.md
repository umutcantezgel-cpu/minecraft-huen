## 2026-09-24 - Modal Accessibility Enhancements
**Learning:** Adding full accessibility properties to modals, such as 'Escape' key support, `role="dialog"`, `aria-modal="true"`, and explicitly associating the title with `aria-labelledby`, provides a significantly better keyboard and screen-reader experience. It's a reusable UX pattern for this design system. Localized ARIA labels like 'Schließen' ensure consistency with the user language.
**Action:** Consistently apply this pattern for all future modal components to maintain keyboard navigability and accessibility compliance.
