## 2024-05-17 - Keyboard Accessibility for Custom Non-Semantic Interactive Components
**Learning:** Custom UI components in `src/components/ui.jsx` (such as `MCButton`, `MCSlot`, and `MCItem`) use non-semantic tags (`div`, `img`). These tags do not naturally receive keyboard focus or respond to keyboard events. Therefore, to ensure keyboard accessibility when they have `onClick` props, they must explicitly include `role="button"`, `tabIndex={0}`, and `onKeyDown` handlers for Enter/Space.
**Action:** When creating or modifying non-semantic tags that function as interactive elements (e.g., buttons, slots) and receive an `onClick` prop, always remember to add `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler to listen for 'Enter' or ' ' (Space) keys, invoking the `onClick` functionality appropriately. Include `focus-visible` styles to show a focus indicator.
