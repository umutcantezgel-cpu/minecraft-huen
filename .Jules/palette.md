## 2025-02-28 - Add Keyboard Accessibility to Custom Interactive Components
**Learning:** Custom interactive components in React (like `MCItem`, `MCButton`, `MCSlot`) built with non-semantic tags (`div`, `img`) lack inherent keyboard accessibility. When adding `onClick` handlers, they must also be assigned `role="button"`, `tabIndex={0}`, and an `onKeyDown` event listener (for 'Enter' and 'Space' keys) to ensure they are focusable and usable by keyboard and screen reader users. Additionally, using `focus-visible` styles with a high contrast ring helps significantly with visual feedback.
**Action:** When implementing new custom UI components or modifying existing ones that rely on `div` or `img` tags for interaction, always add semantic roles, focus states, and keyboard event handlers. Ensure that these focus states have sufficient contrast against their backgrounds (e.g., using `ring-offset-black` or specific background hexes like `#2C2C2C` depending on the surrounding UI element).
