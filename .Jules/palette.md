## 2024-03-21 - Keyboard Accessibility for Custom Interactive Elements
**Learning:** In this application, non-semantic tags like `div` and `img` are heavily used to create custom Minecraft-themed interactive elements (e.g., `MCButton`, `MCItem`, `MCSlot`). Although they feature visually appealing click interactions and `onClick` handlers, they intrinsically lack the keyboard accessibility associated with semantic `<button>` elements, rendering them completely inaccessible to keyboard-only users who expect to interact via the Tab, Enter, and Space keys.

**Action:** Whenever implementing `onClick` functionality on custom elements, explicitly ensure keyboard accessibility by appending `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler to listen for 'Enter' and ' ' (Space). Furthermore, `e.preventDefault()` must be explicitly called within the handler to avert the default browser behavior of scrolling down when the Space key is depressed. Visually, these elements should implement `:focus-visible` styles to indicate keyboard focus.
