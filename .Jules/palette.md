## 2024-10-24 - Full Keyboard Accessibility for Custom Non-Semantic UI Components
**Learning:** Custom UI components built with non-semantic tags (like `div` and `img`) in React need explicit ARIA roles (`role="button"`), focus management (`tabIndex={0}`), and keyboard event handlers (for `Enter` and `Space` keys) when they have click interactions. Also, when handling the `Space` key, `e.preventDefault()` must be called to prevent the default browser behavior of scrolling the page. This pattern is essential for basic keyboard accessibility.
**Action:** When creating or maintaining custom interactive elements (like `MCItem`, `MCButton`, and `MCSlot`) that use `onClick`, always ensure they are paired with `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler to support `Enter` and `Space` activation, preventing default scroll for `Space`.
