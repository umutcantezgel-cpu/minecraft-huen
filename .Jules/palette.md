## 2024-05-18 - Keyboard accessibility on custom interactable components
**Learning:** Custom UI components in `src/components/ui.jsx` (such as `MCButton`, `MCSlot`, and `MCItem`) use non-semantic tags (`div`, `img`). This means they are not naturally keyboard focusable or actionable. If they have `onClick` props, they are interactive and therefore must explicitly include `role="button"`, `tabIndex={0}`, and `onKeyDown` handlers for Enter/Space to ensure full keyboard accessibility. Without `e.preventDefault()` in the `onKeyDown` handler, the Space key will cause the browser default behavior of scrolling the page, which is a poor UX.
**Action:** When implementing custom interactive elements, always ensure they are accessible by keyboard: add `role="button"`, `tabIndex={0}`, handle Enter/Space events properly via `onKeyDown` with `e.preventDefault()`, and add visible focus styles (e.g. `focus-visible:ring-2`).
